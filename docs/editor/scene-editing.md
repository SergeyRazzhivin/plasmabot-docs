# Работа со сценой

## Выбор и перемещение

- Клик - выбрать фигуру; `Shift`+клик - добавить к выбору; рамка - выбрать несколько.
- Перетаскивание двигает выбранное; рамка-трансформер вокруг выбора крутит и масштабирует.
- Круг масштабируется только равномерно - овалов резак не поймёт.
- Колесо мыши - зум к курсору; панорама - перетаскивание пустого места
  (в инструменте Выбор) или любой области средней кнопкой.

## Группы

- Клик по любой фигуре группы выбирает **всю группу** - она двигается целиком.
- **Двойной клик** входит внутрь группы: там можно выбрать и править
  отдельные фигуры (например, подвинуть отверстие).
- `Esc` или клик по пустому месту выводит из группы.
- Импортированный чертёж с отверстиями сразу приходит группой
  "контур + отверстия".

::: tip
Группировка - только удобство редактирования: на рез она не влияет. Сторона
врезки и порядок реза определяются геометрией, а не группами.
:::

## Привязки

Два независимых тумблера в тулбаре: сетка (прилипание к узлам с шагом сетки)
и объектная привязка - к вершинам, центрам, серединам рёбер, пересечениям и
рёбрам соседних деталей; тип точки подписывается у курсора. Точное
позиционирование по зазору - инструментом "Разместить по размеру".

## История

Всё обратимо: фигуры, размеры, группировки, импорт, сброс сцены и даже
настройки реза ходят по `Ctrl+Z` / `Ctrl+Y`. Сцена автоматически сохраняется
и переживает перезагрузку страницы.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `V` | Инструмент Выбор / перемещение |
| `R` | Инструмент Прямоугольник |
| `C` | Инструмент Круг |
| `L` | Инструмент Полилиния |
| `P` | Инструмент Разместить по размеру |
| `D` | Инструмент Размер (текущий тип) |
| `Ctrl+Z` | Отменить |
| `Ctrl+Y` | Повторить |
| `Ctrl+Shift+Z` | Повторить (альтернатива) |
| `Ctrl+G` | Сгруппировать выбранное |
| `Ctrl+Shift+G` | Разгруппировать |
| `Ctrl+D` | Дублировать выбранное |
| `Delete` / `Backspace` | Удалить выбранные фигуры и размеры |
| `Esc` | По приоритету: отменить черновик - выйти из группы - снять выбор |
| `Enter` | Завершить полилинию / подтвердить размещение |

::: tip
Ctrl+X ничем не занят намеренно: во всех программах это "Вырезать", и вешать
на него другое действие опасно для руки оператора.
:::
