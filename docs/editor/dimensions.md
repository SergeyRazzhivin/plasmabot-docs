# Размеры

Размеры - аннотации для контроля чертежа: они не влияют на рез и не попадают
в G-code. Три типа ставятся из тулбара (клик по типу сразу включает
инструмент, линейный - хоткей `D`):

- **Линейный** - две точки и сторона выноски. Линия параллельна измеряемому
  отрезку, поэтому показывает истинное расстояние и держится при повороте
  детали.
- **Угловой** - точка, вершина угла, точка.
- **Диаметр** - клик по окружности; в тексте символ диаметра.

## Ассоциативность

Размер привязывается к точкам геометрии, а не к месту на экране: подвиньте
или поверните деталь - размер пересчитается и переедет вместе с ней. При
простановке курсор прилипает к характерным точкам (вершина, центр,
середина - подписываются у курсора).

## Правка и удаление

- Клик по размеру на канве выбирает его; свойства - в Инспекторе.
- `Delete` удаляет выбранный размер; все размеры видны веткой "Размеры" в
  дереве Объекты.

::: tip
Размеры сохраняются вместе с деталью в библиотеку и вместе со сценой в
.json - при вставке возвращаются на место.
:::
