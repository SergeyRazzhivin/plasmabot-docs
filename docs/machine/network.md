# Сеть и включение платы

На компьютере CB1 платы работают Klipper и Moonraker - редактор общается с
ними по сети. Адреса платы статические:

- **Ethernet:** 192.168.0.250 (основной способ);
- **WiFi:** 192.168.0.251.

Moonraker слушает порт 7125 - адрес подключения по умолчанию:
**http://192.168.0.250:7125**.

## Проверка связи

Включите плату и подождите около минуты (CB1 загружается). Откройте в
браузере адрес платы с портом 7125 - если в ответ пришёл текст со служебными
данными Moonraker, сеть работает и можно подключать редактор.

## Типовые грабли

::: warning VPN перехватывает локальную сеть
Включённый VPN или системный прокси часто заворачивает в туннель и локальные
адреса: редактор показывает "Failed to fetch", хотя плата доступна. При
проблемах со связью первым делом выключите VPN или добавьте исключение для
сети 192.168.0.x.
:::

- Имена вида **\*.local** (mDNS) на Windows не работают - подключайтесь
  только по IP-адресу.
- Компьютер и плата должны быть в одной сети (один роутер, одна подсеть
  192.168.0.x).

## Сервисный доступ (не обязателен)

Для обычной работы SSH не нужен - конфиги платы правятся со страницы
[Конфиг](./config-page.md). Если сервисный доступ всё же понадобился: SSH на
адрес платы, логин **biqu**, пароль **biqu**.
