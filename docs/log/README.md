  отказы» с диагностикой: `claude auth status` + `openclaw channels status`
  разделяют обнулённые токены (#1) и залипший Telegram-поллинг (#2).
- Рабочая машина: MSI Katana GF66 12UE — разблокировка BIOS

  Смарт-авто давил кулеры до 3600 rpm; фикс: Extreme Performance. Под 100%
  нагрузкой ~95°C — ограничение корпуса, лечится PL1-cap, не обдувом.

## 2026-08-26

- Прошивка / sim: два комплекта gcode-тестов для обкатки SCARA-руки на макете.
  `spin-demo.gcode` — FORCE_MOVE (мимо кинематики Klipper), каждый мотор отдельно,
  3 цикла по 2 оборота туда/обратно, 10 рад/с (~95 rpm); пригоден до

  144 сегмента на круг, 10 кругов CCW + 10 CW, оба сустава одновременно, F60000.
- Прошивка / sim: харнес для воспроизведения краша 2026-08-03 (телеоп после мастера
  позиции). `repro-2026-08-03-wizard.gcode` — минимальный сценарий: SET\_KINEMATIC\_POSITION
  X=-330 Y=-470, пауза 9 с, G1 до рабочей точки (F3000). `repro_crash_wizard.py` —
  Python-обёртка над repro\_c\_harness с геометрией CB1 (L1=L2=300, elbow=down);

  timing-окон (0.5 / 0.1 / 0.05 мс) — итого 9 комбинаций.
