# Проблемы и решения

::: warning Черновик
Глава дописывается (Фаза 25, волна 4).
:::

| Симптом | Вероятная причина | Действие |
|---|---|---|
| Редактор пишет "Failed to fetch", плата пингуется | VPN или системный прокси заворачивает локальную сеть в туннель | Выключите VPN или добавьте исключение для 192.168.0.x ([Сеть](/machine/network.md)) |
| Не подключается: плата недоступна по сети | Плата не загрузилась, не тот IP, другая подсеть | Подождите минуту после включения; проверьте адрес (Ethernet 192.168.0.250 / WiFi 192.168.0.251) и что компьютер в той же сети |
| HTTP отвечает, а WebSocket не открывается | CORS в Moonraker | В moonraker.conf нужен блок `[authorization]` с `cors_domains: *://*` ([Первое подключение](/machine/first-connect.md)) |
| Адрес вида имя.local не открывается | mDNS на Windows не работает | Подключайтесь по IP-адресу |
| Красное предупреждение move_guard: False | Страховка движения выключена (макетный режим) | На железе с резаком верните True на странице Конфиг и перезапустите Klipper |
| Klipper ушёл в shutdown | Аварийный стоп, ошибка движения (выход из допустимой зоны руки) | Устраните причину, FIRMWARE_RESTART, заново выставьте позицию мастером |
| Кнопка "Резать" серая | Не выполнена одна из предпосылок | Клик по кнопке или тултип называет причину: подключение, позиция, досягаемость, предупреждения G-code |
| Движения заблокированы после перезапуска | Позиция руки не задана | Пройдите мастер позиции ([Подготовка к резу](./prepare-cut.md)) |
| Часть контура помечена "вне досягаемости" | Деталь вне кольца рабочей зоны руки | Подвиньте деталь ближе к середине кольца ([Рука SCARA](./scara-arm.md)) |
| Предупреждение "открытые пути не режутся" | В импорте незамкнутые контуры | Замкните контур полилинией или исправьте исходный чертёж ([Импорт](/editor/import.md)) |
| После правки конфига кириллица "поехала" | - | Не должна: файл возвращается на плату байт-в-байт; если видите иное - обновите файл с платы кнопкой "Обновить" |
